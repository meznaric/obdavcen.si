# How to write a blog post
 - Trenutno imamo glavno stran (/) s kalkulatorjem na katerem lahko primerjas razlicne tipe podjetja.
 - Za vsak H2 naslov napiši 3–5 paragrafe ali seznamov, z dolžino med 150 in 300 besedami. Pazi, da vsebina ostane jasna, brez preobremenitve bralca.
 - Tvoja naloga je da napises nove blog poste. Optimizirane za SEO, kjer slovenski podjetniki iscejo "SP davki" "SP Prispevki", "izracun place", "DOO" in podobno.
 - Pri tem moras upostaviti vse podatke, ki jih imaš v datoteki DATA.md. Ugotoviti moras razlicne zanimivosti za razlicne tipe podjetij in to izpostaviti.
 - Uporabljaj boldane texte. Linkaj med različnimi tipi podjetja. Vključi kazalo. Uporabi alert komponento.
 - Dodaj račune znotraj code blockov o tem kako izračunati prispevke na podlagi taxCalculator in ostalih utilsov.
 - Na voljo imaš daisyui, tailwindcss. Uporabi bogate komponente.
 - Pisi pravilno slovnicno besedilo. Uporabljaj sumnike.
 - Uporabi markdown x format. Primer template-a imas v app/routes/blogs.template.mdx
 - Pravilno nastavi heading in description da bo primerno za SEO.
 - Uporabljaj ikone po potrebi in prilagodi barvo.
 - Uporabljaj alerte po potrebi.
 - Prikaži formule kot code blocks.
 - Pokaži podatke kot tabele
 - Assume what I may have missed.
 - Dodaj povezave do zakonov pri različnih podatkih

Blog post naj ima poglavja strukturirana v naslednjem formatu:

 - Uvod
 - ...
 - Izračun davkov in prispevkov
    - Kako se računajo davki?
    - Kako se računajo prispevki?
    - Kako se računa dohodnina?
 - Kdaj izbrati X?
 - Kdaj X ni prava izbira?
 - X ali A
 - X ali B
 - X ali C
 - Zaključek
 - Relevantni zakoni:
   - Links to https://zakonodaja.com/zakon/X for example https://zakonodaja.com/zakon/zdoh-2 with short descriptions
