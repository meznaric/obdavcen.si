## Kako se računa davek od dohodkov pravnih oseb (DDPO)?

Pri d. o. o. se najprej obračuna davek od dohodkov pravnih oseb (DDPO):

```typescript
Dobiček = Prihodki - Odhodki - Plače - Prispevki delodajalca
DDPO = Dobiček × stopnja DDPO
Čisti dobiček = Dobiček - DDPO
```

Stopnja DDPO je {Math.round(ddpoTaxRate * 100)} % in velja za davčna leta od 2024 do 2028.

## Kako se računa davek od dividend?

Ko se odločiš za izplačilo dobička, se obračuna še davek od dividend:

```typescript
Davek od dividend = Izplačane dividende × stopnja davka od dividend
Neto dividende = Izplačane dividende - Davek od dividend
```

Davek od dividend znaša {Math.round(dividendsTaxRate * 100)} % in je dokončen.

## Kako se računajo prispevki?

Pri d. o. o. imamo dva glavna načina izplačil:
1. **Plača** (mesečno izplačilo)
2. **Dividende** (izplačilo dobička)

### Izračun plače

Primer izračuna plače:
```typescript
Bruto1 = Osnovna plača
Bruto2 = Bruto1 + prispevki delodajalca

Neto plača = Bruto1 - prispevki zavarovanca - dohodnina (progresivna lestvica) - OZP
```

## Kako se računa dohodnina?

Dohodnina se računa po progresivni lestvici od davčne osnove, kar pomeni, da plačamo odstotke za vsak dohodninski razred, v katerem smo.

Dohodninska lestvica za leto 2026:

<ul>
  {incomeTaxBrackets.map((razred, i) => {
    const od = incomeTaxBrackets[i - 1]?.maxNumber;
    const stopnja = `${Math.round(razred.percentage * 100)} %`;
    if (od === undefined) return <li key={i}>{stopnja} do {formatCurrency(razred.maxNumber)}</li>;
    if (razred.maxNumber === undefined) return <li key={i}>{stopnja} nad {formatCurrency(od)}</li>;
    return <li key={i}>{stopnja} od {formatCurrency(od)} do {formatCurrency(razred.maxNumber)}</li>;
  })}
</ul>

Kako se izračuna davčna osnova?

```
Davčna osnova = Bruto1 plača - Prispevki zavarovanca - OZP - Splošna davčna olajšava
```

## Kdaj izbrati d. o. o.?

Točne številke so odvisne od tvojih prihodkov in stroškov, zato jih preveri v [kalkulatorju](/).

- Ko pričakuješ **prihodke nad mejo za normirance** (povprečje zadnjih dveh let nad {evri(normiranMaxRevenue)}) ali imaš **visoke stroške**
- Ko imaš **stabilno poslovanje**
- Ko želiš **zaščititi osebno premoženje**
- Ko načrtuješ **zaposlovanje**
- Ko želiš **prožnost pri izplačilih**
- Ko razmišljaš o **prodaji podjetja** v prihodnosti

Minimalna plača z dividendami je davčno ugodnejša od največje plače pri skoraj vseh višinah prihodkov: pri {evri(100000)} prihodkov brez stroškov ti ostane {evri(razlikaMinMax100)} več na leto. Višja plača pa ti prinese višjo pokojninsko osnovo in višja nadomestila (bolniška, starševska), zato je izbira odvisna od tega, kaj ti je pomembneje.
